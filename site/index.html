For Muse and other tools

Start from the feed: it lists every batch and post with absolute URLs for the Reel, cover, stills, caption, alt text and the first day each post can be scheduled.

feed.json

  • Schedule a post on or after schedule_from (Instagram allows 30 days ahead), at date + time in Mountain Time (Calgary).
  • Post the Reel from reel.url with the cover from reel.cover_url. Paste caption exactly. Add alt_text.
  • If reel is null (quiet days like Remembrance Day), post the still as a single image, with no sound.
  • The Special events tab is rolling: holiday posts for the year ahead. Schedule each one when its schedule_from date arrives.
  • Each batch also has plan.json and captions.csv (links below). Files only change when a new batch is pushed.
